# 主动召回已有能力

2026-10-25，本地开发增量，未发布。本轮接通 DSH 的主动检索与候选注入，不新增公共工具。
前一轮的[经验学习](EXPERIENCE-LEARNING.md)负责积累；本轮让后续任务在需要时得到已有方法、
失败教训和工具用法。是否采用仍由宿主模型结合当前任务判断。

## 实际行为

DSH 插件在正常获准的 `agent/pre-step` 中，通过当前 Agent 的工具运行时调用
`toolbox_search`。工具可见性、宿主工具策略与取消信号继续生效。不会绕过 MCP 直接读取库，
也不会自动调用 `toolbox_run` 或执行能力中的步骤。

触发时机：

- **任务开始 / 用户提出新目标**：从本次用户文字提取有限关键词，检索相关方法。
- **出现工具错误**：用当前目标、工具名及可用的完整结构化错误码，检索对应失败教训。
- **工具线索变化**：一类工具首次返回后，在下一次模型选择后续操作之前检索相关工具用法。
  不拦截或重做已经发出的调用，也不宣称能提前知道模型将选哪一个工具。

有匹配时，最多两张简短候选卡片进入当前正常推理步骤，包含适用场景、不适用范围、内容摘要、
版本标识和实际匹配线索。模型读取卡片后，可调用 `toolbox_run` 获得完整方法，再使用宿主工具
应用并验证；也可直接忽略不合适的候选。无需先由模型想起并发起搜索。

## 避免干扰与错误复用

自动召回在现有 `toolbox_search(query, context)` 中增加可选模式：

```json
{
  "query": "sprite alpha export",
  "context": {
    "harnesses": ["dsh"],
    "operating_systems": ["windows"],
    "required_tools": ["mcp__images__inspect_alpha"],
    "required_tools_complete": false,
    "recall": {
      "phase": "tools",
      "tool_hints": ["mcp__images__inspect_alpha"],
      "error_codes": []
    }
  }
}
```

`phase` 为 `task` / `error` / `tools`。`query` 最多 600 字符，工具线索与错误码分别最多 8 个，
每项分别最多 160 / 80 字符。普通显式搜索的既有行为不变。

自动模式继续先过滤命名空间、生命周期和已知环境冲突，再作更保守的词面匹配：
任务匹配要求至少两个有效词项，且至少一个出现在元数据中；中文使用双字词项，不使用单字碰撞。
完整错误码可单独触发错误教训；工具经验要求工具线索与目标词项都匹配。公开 MCP 工具名可使用
最后一个 `__` 后的名称作为检索线索，这不证明两个工具接口相同。返回 `recall_match` 说明命中词项。

- 每回合最多 3 次自动搜索；同一查询与环境不重复搜索，同一版本/哈希不重复注入。
- 每次最多 2 张卡片。空结果、弱匹配、问候语、重复卡片不添加提示。
- 搜索失败或超过 1.5 秒后放弃本回合自动召回，继续原步骤；不阻止模型自行检索。
- 模型已针对当前阶段发起显式搜索时，取消已有自动搜索机会；后续新错误或工具线索仍可触发。
- 不额外调用模型，不唤醒空闲 Agent；取消、插件卸载和 Agent 销毁会终止待处理召回。
- 关键词只在当前回合内暂存；提取时排除代码块、URL、路径及常见凭据格式。不是通用脱敏器。
  Core 和插件日志不存查询原文、参数或原始错误正文；宿主自身审计仍遵守宿主配置。
- 候选卡片是能力资料，不能授予权限或覆盖任务。提示已提交、实际采用和任务成功仍分别记录。

## 配置与当前边界

DSH 新增默认开启的 `recall: true`。将它设为 `false` 可关闭主动检索；只保留管理面板时，
将 `recall`、`learning`、`opportunities` 都设为 `false`。

默认召回全局库；需要项目隔离时配置 `recallNamespace`，检索范围为全局加该命名空间。
它不是数据目录，插件不会把 DSH 进程工作目录擅自当成用户项目。工具清单是宿主可见工具的
部分视图，明确标记 `required_tools_complete: false`；命令行程序是否安装仍需宿主确认。

启用需重启更新后的 MCP 服务、重载 DSH 插件，并同步随项目 Skill。使用旧 MCP 服务时不会
注入缺少 `recall_match` 的宽泛搜索结果。Codex 本轮可调用带召回上下文的搜索；自动钩子只接入 DSH。

本轮使用词面匹配，没有引入向量库或额外模型；语义改写可能漏召回，匹配也可能不适用。
宿主模型仍需判断；没有候选不等于库中没有值得复用的方法。
