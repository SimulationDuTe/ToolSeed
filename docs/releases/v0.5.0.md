# ToolSeed v0.5.0

让 Agent 将值得重复利用的任务方法、错误教训与工具用法转化为能力，在合适时机召回、应用并更新。
本版本仍为 Alpha。

## 新增与改进

- 经验学习：保留方法、适用条件、失败教训、工具配方和复用检查，脚本无需作为能力主体。
- 主动召回：DSH / Codex 根据任务、结构化错误与工具线索取得少量候选，由宿主模型判断是否采用。
- 使用反馈：观察绑定原能力、版本、哈希和实际交付，重复使用不会仅因任务不同而再建一份能力。
- 修订门禁：完整修订校验读取基线；DSH 可通过宿主工具执行新场景与回归检查后启用候选版本。
- 宿主适配：共享学习状态规则，保留各自权限与事件接入；DSH 支持已验证的 rc.2 / rc.3。
- 完整升级：固定 GitHub commit，独立安装 Core，同步 Skill、MCP 和适配器，备份并试迁移已有库后自检。
- 改善中英文场景与别名召回，保留版本绑定的结构化错误经验，拆分 Core 领域服务。

## 安装与升级

PyPI 发布成功后：

```bash
python -m pip install --upgrade toolseed==0.5.0
toolseed update codex --ref v0.5.0
# DSH 用户先完全退出 Desktop，再运行：
toolseed update dsh --ref v0.5.0
```

也可以安装 GitHub Release 附带的 wheel。升级继续使用实际宿主中的能力库目录，不自动合并两个库。

## 兼容与范围

- Python 3.11+，依赖官方 MCP SDK 2.3+（小于 3）与 PyYAML 6。
- 数据库 schema 从 v6 升到 v7；完整升级会备份并在副本上验证迁移。
- 五个公共 MCP 工具不变。完整定向修订需提供读取所得 `base_version_id` 与 `base_content_hash`。
- Core 交付指引，操作由宿主执行；方法交付、模型自述与工具活动均不能替代独立任务结果。
- 两轮真实 DSH 模型任务观察到经验沉淀与跨会话复用；Codex 原生链路验证含脚本驱动场景。
  这些证据不构成普遍成功率、稳定自主学习或提效百分比的证明。
- 本地基线检查为 Python 442 项（1 项条件跳过）、Node 157 项；发布结果以 Actions 实际检查为准。
