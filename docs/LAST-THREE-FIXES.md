## 同版本运行配置更新

部署身份同时比较源码和运行配置：Python、数据目录，以及 Codex 的 Home、Node、工作目录、MCP 名称，或 DSH 的 Home、命令。相同源码更换这些参数会重新走安装前检查和适配安装器，复用已取得的源码目录；配置完全相同仍返回 `already-installed`。

旧安装记录没有 `runtime_config` 时，下一次安装会完整核对、应用并补充记录。显式修复用户改动或文件漂移：

```bash
python -m toolseed install codex --ref /path/to/ToolSeed --repair --codex-home /path/to/codex-home --data-dir /path/to/library
```

`update` 同样支持 `--repair`。Codex 的 MCP 配置仍需指向所选能力库，配置不匹配时预检拒绝，不会静默迁移能力库或修改其他 MCP。切换宿主 Home 会在新位置应用，旧位置不自动卸载。

同源码重配置失败不会覆盖该目录的上一次成功部署记录，也不会形成指向自身的 previous 指针。失败响应只声明 `previous_active_preserved`，不再把保留旧指针称为完整回滚；既有安装器的全文件失败恢复仍是独立问题。

## 结构化错误教学

Schema v7 为版本新增可空 `knowledge_json`。新学习的 method、triggers、aliases、pitfalls、tool_recipes、checks 和后续增量修订结构与正文一起保存，交付时返回 `result.experience`。结构必须通过格式检查并能精确还原正文，不能用失配的结构豁免内容审查。

- 推荐方法、观察、应对、工具用法、别名和验证检查继续接受内容门禁。
- 仅在 `pitfalls.attempt` 中出现的高影响操作可作为反例保留原文，以 JSON 引用并明确标注“错误材料，禁止执行”。首次仍是候选，`content_review.status=verification_required`；独立版本验证通过后，才允许通过既有提升流程成为可复用版本。
- `edit_required` 表示推荐内容或反例本身仍不适合通过此审查路径。凭据不会入库，权限绕过/外泄类反例不适用这项结构化复核。
- 普通正文写“反例”不会获得豁免。观察不证明根因，验证声明不替代独立检查，交付不记为采用或任务成功。

完整定向修订继续检查实际读取的版本与哈希；增量 reuse 修订保留原结构及验证门禁。管理面板不会通过结构字段暴露候选正文。
DSH/Codex 的 ToolSeed 文本结果回退解析上限同步调整为 128 KiB，容纳正文与结构并存的交付；仍拒绝超大结果，普通工具失败解析的限制不变。

迁移只加列：旧内容、哈希和生命周期状态保持不变，不从旧文字猜测结构或自动提升。旧反例需经读取后提交完整定向学习修订。只读面板同时支持 v6/v7，不执行迁移；旧版宿主应同步更新 Core 和 Skill 后使用新字段。

## 召回覆盖与读取成本

新增 `experience.aliases`，最多 12 项、每项 160 字符，用于实际概念别名、同义表达或中英文等价表述。aliases 与 triggers 独立保留并参与场景匹配。可选别名不会声明工具兼容性或授予权限。

本地概念表补充透明通道、导出、精灵、背景、超时、连接、权限、配置等有限中英文表达。查询和方法两侧都归一化；匹配理由提供 `recall_match.concepts`。自动召回仍需要多个独立线索；同一概念的多个同义词不凑成多条线索。错误码支持含连字符的完整标识，子串不算命中。

交付候选改为一次联表读取当前版本，移除每个能力两次额外 SELECT。103 个能力返回 3 张卡片的样本从审查时 215 次 SELECT 降为 **11 次**；3 个和 103 个能力的查询次数相同。结果卡片的验证、学习和复用摘要仍会读取证据，因此不是整次请求只有一条查询。

这是确定性词项与概念匹配，未加入向量、外部翻译服务或额外模型调用。概念表覆盖有限，长尾场景应由模型留下明确的 aliases/triggers；仍须核对真实适用条件。底层仍扫描当前候选集合，不声称已解决任意规模库的排序成本。
